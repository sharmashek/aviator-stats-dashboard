# Aviator Stats Dashboard

A legal Aviator-style stats dashboard starter built with Node.js, Express, SQLite, and bcrypt.

This project is intentionally designed for honest session tracking and historical analysis. It does not claim to predict gambling outcomes.

## Features

- User registration and login
- Secure password hashing
- Session-based authentication
- Add round entries with multiplier and result
- Dashboard with totals, win rate, average multiplier, streak logic
- Recent history view

## Tech Stack

- Node.js
- Express
- SQLite
- bcryptjs

## Run locally

1. Install dependencies:
   npm install
2. Start the app:
   npm start
3. Open:
   http://localhost:3000

## Default behavior

- Visit `/register` to create an account
- Use `/login` to sign in
- Use `/dashboard` after login

## Notes

This is a legitimate project starter for tracking round data, not a betting prediction engine.
